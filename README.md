# 🎓 Student Performance Prediction

A **Python Machine Learning project** that predicts a student’s **final grade (G3)** using **Linear Regression** based on previous grades, study time, free time, and absences.

The app features a **Tkinter-based GUI** where users can input student data and instantly get grade predictions along with **personalized study suggestions**.

### ⚙️ Tech Stack

* Python 🐍
* Scikit-Learn 🤖
* Tkinter 🪟
* Pandas, NumPy

### 📊 Dataset

Trained on a sample dataset **`FinalStuper.csv`** for prediction and testing.
